# Agent instructions

## Agent skills

### Issue tracker

Issue 以本地 Markdown 文件形式跟踪,位于 `.scratch/<feature>/`。See `docs/agents/issue-tracker.md`.

### Triage labels

使用默认的五个规范 triage 标签(`needs-triage` / `needs-info` / `ready-for-agent` / `ready-for-human` / `wontfix`),原样使用。See `docs/agents/triage-labels.md`.

### Domain docs

Single-context 布局:仓库根目录一个 `CONTEXT.md` + `docs/adr/`。See `docs/agents/domain.md`.
